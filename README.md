# Refugio de exámenes

Aplicación web personal mobile-first para acompañar una semana de exámenes.

## Stack

- Frontend: Angular 21.2.19 + TypeScript 5.9
- Node compatible: 22.17.0 (Angular 21 admite ^22.12.0)
- Backend preparado: Python + FastAPI
- Persistencia prevista: JSON

## Funcionalidades previstas

- Abrir cuando...
- Modo estudio / Pomodoro
- Mensajes de motivación
- Abrazo de emergencia
- Música
- Estado de ánimo
- Cuenta atrás
- Easter eggs
- Pantalla final

## Arranque rápido

```powershell
cd frontend
npm install
npm start
```

Abrir `http://localhost:4200`.
